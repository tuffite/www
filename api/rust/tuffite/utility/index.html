Module utility 

Expand description

Sandboxed utility implementations and browser-side clients.

Rust and V8 definitions share the utility attribute. Rust implementations use Utility; V8 definitions use V8 and v8::ModuleSource. Both use supervised Chromium utility processes and session transport.
