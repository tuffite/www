Rust API

tuffite 公共门面、应用生命周期和构建辅助 API。

应用入口#

  • Browser：实现 new(BrowserContext) 创建 browser 进程状态。
  • app::Builder<B>：注册 browser 命令并处理进程启动准备。
  • BrowserContext：访问配置字节、事件、执行器、原生 ShellAPI、具名 Rust 和 V8 utility。
  • #[tuffite::main(browser = App, utilities(Indexer, Parser))]、#[tuffite::browser]、#[tuffite::utility(name = "parser")]：显式组合进程定义。

Feature 开关与构建辅助#

build 启用 Distribution 解析、ShellAPI 代码生成和应用构建辅助。cli 默认启用，提供 tuff 二进制；async 启用 ChromiumTask 集成。应用设置 default-features = false 避免引入 CLI 依赖。build::framework::Resolver、build::shell_api::Codegen 和 build::Builder 属于构建 API，运行时 Builder 是另一种类型。

toml
[dependencies]
tuffite = { version = "0.1.0", default-features = false }

[build-dependencies]
tuffite = { version = "0.1.0", default-features = false, features = ["build"] }
