tuffite.json

基于权威 schema 生成、可搜索的配置参考。

应用配置文件#

根对象要求 schemaVersion = 2 和 app。app 要求 identifier、security、shellApi 和 assets。build 与 bundle 可选。additionalProperties 为 false 时拒绝未知属性。使用 tuff check 验证；类型正确并不代表路由和权限语义正确。

json
{
  "$schema": "https://tuffite.org/schema/v2/tuffite.schema.json",
  "schemaVersion": 2,
  "app": {
    "identifier": "org.example.myapp",
    "security": { "capabilities": [] },
    "shellApi": { "namespace": "myapp", "definitions": ["shell_api.d.ts"] },
    "assets": []
  }
}
